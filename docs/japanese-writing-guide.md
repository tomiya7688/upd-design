# 日本語文書の書き方

UPD の説明では、読者が「その仕事を UI・Process・Data のどこに置くか」を判断できるように書きます。

## 担当を明確にする

「処理を行う」だけで済ませず、「UI は入力を受け取る」「Process は金額を計算する」「Data は保存する」のように、誰が何をするかを書きます。

## 用語を説明する

「層」は担当する仕事ごとのまとまり、「責務」はその層が担当する仕事です。専門用語は、最初に使う場所で短く説明します。

## 境界を具体例で示す

「UI は表示を担当する」に続けて、「割引額を計算するのは Process、金額を見やすく表示するのは UI」と書くと、両者の違いが伝わります。

## 説明と規則をそろえる

説明は[基本規則](../specification/README.md)に合わせます。例として挙げた商品の種類や画面の形を、そのまま UPD 全体の条件にしません。

ひとつの段落でひとつの話題を扱い、結論、具体例、理由の順に説明します。
