# 境界チェックツールの利用

[English](en/checker.md)

**UPD の境界違反が検出された変更は、違反を修正するまで取り込まない。**

検査方法と検出範囲は [ツールの説明](../../tools/README.md) に示す。利用プロジェクトの CI に境界チェックを組み込み、必須チェックとして扱う。

## 対応言語

現時点では、Python、C#、Rust、Go、Kotlin、C++、なでしこ3の **代表的な静的参照構文**を検査する。

このツールは、各言語のすべての構文や責務を解析するものではない。対応構文と既知の限界は [ツールの説明](../../tools/README.md) に定める。

## 違反の扱い

検出した境界違反、未分類ソース、認識可能な未対応拡張子、解析・解決不能、設定不備では非ゼロの終了コードを返す。CI はこれを失敗として扱う。

**検査を通す目的で、違反のあるファイルを検査範囲から除外してはならない。**

このリポジトリの GitHub Actions が検証するのは、チェックツール自体の動作である。利用先プロジェクトの境界を検査するには、**利用先の CI への導入と必須チェックの設定**が別途必要となる。

## 検出範囲の限界

UI 内に割引計算を直接実装した場合など、層間参照を伴わない責務違反は現在の依存関係検査では検出できない。完全修飾名、マクロ、動的参照にも未対応の部分がある。

**検査の成功は、UPD の全規則への適合を保証しない。** [必ず守る境界](境界.md) と [レビューのチェックリスト](レビュー.md) に基づく確認を併用する。

違反を許容する例外の追加ではなく、解析器の精度と適用範囲の拡充によって検出力を高める。
