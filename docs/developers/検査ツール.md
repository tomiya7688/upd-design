# 境界チェックツールの利用

[English](en/checker.md)

UPD の境界違反は、修正するまで取り込みません。

[tools の使い方と検査範囲](../../tools/README.md)を参照し、利用するプロジェクトのCIに境界チェックを組み込みます。

## 対応言語

Python のほか、C#、Rust、Go、Kotlin、C++、なでしこ3の**代表的な静的参照構文**を検査します。

現在のツールは各言語の構文・責務のすべてを理解するものではありません。対応する構文と未対応の範囲は [ツールの説明](../../tools/README.md) に示しています。

## 違反の扱い

違反、未分類ソース、未対応の拡張子、解析・解決不能、設定不備は非ゼロ終了としてCIを失敗させます。ファイルを検査範囲から外して違反を隠してはいけません。

このリポジトリの GitHub Actions はチェッカー自身のテストです。**利用プロジェクトを守るためには、そのプロジェクトへの検査導入と必須チェック設定が必要です。**

## 検査の限界

UI 内に割引計算を直接書くなど、層をまたぐ参照を伴わない責務違反は現在検出できません。完全修飾名、マクロや動的な参照にも言語ごとの未対応部分があります。

**ツールが成功してもUPDの全規則に適合した保証にはなりません。** [必ず守る境界](境界.md)と[レビューのチェックリスト](レビュー.md)を使って確認します。

違反を通すための例外を増やすのではなく、解析器の対象範囲と精度を拡充していきます。
